## Структура

- `src/ИАД_4.py` — исполняемый сценарий;
- `src/data/` — исходные файлы, необходимые для воспроизведения;
- `src/results/` — проверенные результаты (графики, `metrics.json`, где применимо — веса моделей `.pt`);
- `src/requirements.txt` — список пакетов.
- `src/NN_common.py` — общие компоненты обучения (только ЛР 3–4).

## Запуск (Windows CMD / PowerShell)
Из папки `lab_4`:
```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r src\requirements.txt
.venv\Scripts\python.exe src\ИАД_4.py
```
Результаты создаются в `src/results`. Не удаляйте `src/data` и не переименовывайте файлы исходных данных. При повторном обучении возможны небольшие колебания чисел на другой версии библиотек/аппаратуре. Для визуализаций выбран `matplotlib` с сохранением в PNG; открывать окно графика не обязательно.

## Источники и особенности
Те же данные и та же архитектура, что в ЛР №3. Применены Bernoulli RBM со шкалой данных [0,1], перенос весов и bias в классификатор; baseline и AE повторно обучены для сопоставимости.

## Проверенные показатели
- Credit Approval: baseline macro-F1=0.8249, autoencoder macro-F1=0.8184, RBM macro-F1=0.8184
- WDBC: baseline macro-F1=0.9621, autoencoder macro-F1=0.9695, RBM macro-F1=0.9621

**Примечание:** При повторном запуске программы файлы в `src/results/` могут быть перезаписаны. Word-отчёт не формируется автоматически из скрипта: приложена отредактированная версия с проверенными результатами текущего запуска.
