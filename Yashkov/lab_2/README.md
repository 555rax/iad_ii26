## Запуск (Windows CMD / PowerShell)
Из папки `lab_2`:
```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r src\requirements.txt
.venv\Scripts\python.exe src\ИАД_2.py
```
Результаты создаются в `src/results`. Не удаляйте `src/data` и не переименовывайте файлы исходных данных. При повторном обучении возможны небольшие колебания чисел на другой версии библиотек/аппаратуре. Для визуализаций выбран `matplotlib` с сохранением в PNG; открывать окно графика не обязательно.

## Источники и особенности
Wisconsin Diagnostic Breast Cancer (WDBC), 569×30, данные через `sklearn.datasets.load_breast_cancer`; метка Diagnosis соответствует 2-му столбцу исходного UCI WDBC, ID создан только для демонстрации структуры и исключён из расчётов. t-SNE 3D строится на фиксированной подвыборке 350 наблюдений.

## Проверенные показатели
- Автоэнкодер 2D: конечная MSE=0.008792.
- Автоэнкодер 3D: конечная MSE=0.008270.

**Примечание:** При повторном запуске программы файлы в `src/results/` могут быть перезаписаны. Word-отчёт не формируется автоматически из скрипта: приложена отредактированная версия с проверенными результатами текущего запуска.
