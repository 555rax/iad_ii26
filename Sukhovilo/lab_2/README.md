## Содержание

- `doc/ИАД_2.docx` — отчёт Word (PDF при необходимости экспортируйте самостоятельно).
- `src/ИАД_2.py` — основной исполняемый Python-файл.
- `src/data/` — исходные данные, включены в архив.
- `src/results/` — фактически полученные результаты, графики, JSON с метриками.


## Как выполнить

1. Установить Python 3.10+ и открыть терминал/PowerShell.
2. Перейти в папку `src` данной лабораторной.
3. Создать окружение: `python -m venv .venv`
4. Включить окружение Windows: `.venv\Scripts\activate`
5. Установить зависимости: `python -m pip install -r requirements.txt`
6. Запустить: `python ИАД_2.py`
7. Проверить `results/metrics.json` и рисунки. Числа в Word соответствуют выполненным тестовым запускам.

## Замечания

- Скрипт использует абсолютные пути от расположения исходного файла, поэтому данные не теряются при запуске.
- Никакие числа в `metrics.json` не подставлены вручную.
- В обучении применены фиксированные случайные зерна для воспроизводимости; версии зависимостей могут немного влиять на результат.
- Эксперименты выполнялись на CPU.

- Трехмерный t-SNE использует фиксированную подвыборку 400 примеров, 2D — 1000 для доступного времени вычислений; исходные 5620 объектов сохранены и используются для автоэнкодеров и PCA.
