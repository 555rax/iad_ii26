## Запуск (Windows CMD / PowerShell)
Из папки `lab_1`:
```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r src\requirements.txt
.venv\Scripts\python.exe src\ИАД_1.py
```
Результаты создаются в `src/results`. Не удаляйте `src/data` и не переименовывайте файлы исходных данных. При повторном обучении возможны небольшие колебания чисел на другой версии библиотек/аппаратуре. Для визуализаций выбран `matplotlib` с сохранением в PNG; открывать окно графика не обязательно.
